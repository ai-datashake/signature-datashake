Comment l'installer dans Gmail

  1. Renseigne tes infos dans le formulaire.
  2. Clique sur Télécharger le HTML.
  3. Ouvre le fichier téléchargé dans ton navigateur (double-clic dessus).
  4. Sélectionne toute la signature (Cmd+A) puis copie (Cmd+C).
  5. Dans Gmail, va dans Paramètres > Voir tous les paramètres > Signature.
  6. Colle (Cmd+V) dans le champ de la signature, puis enregistre les modifications en bas de page.
